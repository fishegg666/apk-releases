## 📱 功能介绍

### 🧮 计算器
简洁实用的四则运算计算器，支持加、减、乘、除运算，带表达式实时显示和历史记录。

### 🔄 单位换算
支持**长度**、**重量**、**温度**三大类单位的自由换算：
- 长度：毫米、厘米、米、千米、英寸、英尺
- 重量：毫克、克、千克、吨、磅、盎司
- 温度：摄氏度、华氏度、开尔文

### 🎲 随机数生成
灵活的随机数生成器：
- 指定最小/最大值范围
- **单个随机数**快速生成，大号字体醒目展示
- **批量生成** 1~20 个随机数，弹窗显示全部结果

### ⚖️ BMI 计算
健康指数计算工具：
- 输入身高(cm)和体重(kg)自动计算 BMI
- 中国标准分类：偏瘦 / 正常 / 偏胖 / 肥胖
- 附带**健康建议**和参考标准表

### 📅 日期计算
实用的日期差计算工具：
- 选择开始日期和结束日期
- 自动计算相差 **年/月/天**
- 统计**工作天数**（排除周末）
- 中文日期格式显示（含星期）

### 🎨 颜色工具
可视化颜色调配工具：
- **RGB滑块**实时调色，支持透明度调节
- 实时显示 **HEX** 和 **RGB** 颜色值
- 12 种**预设颜色**一键切换
- 带阴影的实时颜色预览

### 🎲 摇骰子
多骰子同时摇动，带弹性动画效果：
- 支持 1~6 个骰子同时摇动
- 统计总数、最大、最小、平均值

### 🪙 抛硬币
带翻转动画的抛硬币工具：
- 真实硬币翻转动画效果
- 记录正面/反面次数统计

### 🔑 密码生成器
自定义密码生成工具：
- 可配置长度、大小写、数字、符号
- 实时密码强度指示器
- 一键复制密码

### 📝 文字计数
全面的文字统计工具：
- 统计总字符、无空格字符、单词数、行数
- 汉字数、数字数统计
- 预估阅读时间

### 🔢 进制转换
支持二进制/八进制/十进制/十六进制互转：
- 输入自动转换到所有进制
- 彩色标签区分不同进制

### 🍅 番茄专注
番茄工作法计时器：
- 25分钟专注 + 5分钟休息模式
- 每4个番茄后长休息15分钟
- 圆形动画计时器，震动提醒
